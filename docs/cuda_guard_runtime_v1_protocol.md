# CUDA action and baseline runtime qualification

Frozen before tasks/outcomes, September 27, 2026. Prerequisite: audited H200 qualification job 27714861 passed exact greedy continuation, 8k context and four-item batching. Its measured throughput was only 5.78 output tokens/second for that probe; GPU access is not yet a demonstrated speedup over MLX.

Run two fresh development tasks, seed 1091027, one repeat for continue, segmented sham and segment-boundary GUARD adaptation (up to six episodes). Keep all ineligible cases without replacement. Same 2,048 generated-token allowance including initial and discarded work, 256-target/384-cap checkpoint and 128-token final reserve; BF16 CUDA with Python tokenizer is a separate backend/protocol, never pooled with MLX 4-bit. No Jev requests or closed test data.

The CUDA adapter records base-distribution token log probabilities and full-vocabulary entropy, uses independent KV caches per call, seeded temperature/top-p sampling, and exact token prefixes. It explicitly differs in numerical precision and RNG implementation from MLX. Before any outcome episode, an in-allocation greedy resume check exercises the adapter. Source/model hashes, pinned module versions, every call and selector decision are recorded. Preflight GPU work is separate from hypothetical episode accounting and remains included in total Slurm GPU-hours.

Bound: one standard-tier H100/H200/B200, four CPUs, 32 GiB RAM, two hours, cooperative 7,000 seconds. Uses only the already cached pinned Qwen3-4B snapshot; no download. Per-call timeout remains 180 seconds, so report any timeout and truncation explicitly rather than claiming the token allowance was fully used. The experiment qualifies runtime, timing, cost and actions, not efficacy. Independent whole-run audit must pass before interpreting outputs. If no natural branch occurs, qualify forced-branch execution separately; do not report forced branching as policy success. Broader batch/scaling experiments require observed throughput/utilization and this gate, not merely a successful allocation.
