# Prior-art boundary and next experiment, September 29, 2026

## Decision

Do not pitch “a judge monitors chain-of-thought and decides whether to verify, repair, branch, trim, or stop” as a new method. Direct precedents already implement test-time process verification, rollback/feedback, state-dependent verifier allocation, same-prefix branching, and action-conditioned intervention-value estimation. **The core estimand and data-collection protocol we previously proposed are already directly present in prior work. We have not validated a methods-level novelty gap.** A possible remaining study is only an empirical comparison of Jev as a particular judgment source against cheap/local features inside an established intervention-control design. This extension is not yet a defensible novelty claim, and its Jev-dependent form is on hold pending contract clarification.

## Next research dependency

1. Keep closed v1 data excluded. Do not expand the arithmetic-construction correction study under its failed opportunity gate.
2. Before launching a new efficacy study, select one compatible public benchmark/action contract and decide whether to first reproduce/adapt *interwhen* as a strong executable-verifier baseline or use a different domain where this action is genuinely distinct. Freeze exact data revision, model/runtime, checkpoint eligibility, interventions, common terminal validator, total-budget accounting, timeout policy, sample-size target and baseline semantics.
3. Qualify the open-weight serving stack and data access with bounded infrastructure checks before a large snapshot download. Prefer the official runner when compatible; otherwise call it an adaptation. Do not start inference on a login node.
4. Jev-output-conditioned controller training, distillation, or development of a Jev-based similar/competing service is held pending written TypeSafe clarification. The current [Master Customer Agreement §2.3(b)](https://typesafe.ai/legal/mca) restricts using the Service or Output to train a model to imitate outputs or develop/facilitate a similar or competing product/service. This is an operational reading, not legal advice. Until cleared, spend no Jev API budget on that dependent study; local-only baseline and outcome-value work may continue.
5. **No methods-level gap is currently established.** Before retaining a research-paper framing, perform a systematic search around action-conditioned intervention advantage, prefix branching, causal repair, judge-feature ablations and OOD transfer; compare the exact estimands/actions/data/compute of each paper in a dated table. A potentially defensible deliverable is a transparent, cost-matched empirical source comparison (Jev vs independent local/cheap signals) across a clearly new held-out horizon/transfer regime, but only if the exact contribution survives that search and TypeSafe permits it. No new result here establishes positive intervention value, Jev incremental value, OOD transfer, or discovery benefit.
